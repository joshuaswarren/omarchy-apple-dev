# Ubuntu 24.04 container: the toolchain and no-xcode steps without pacman

2026-10-09. Clean Ubuntu 24.04 container, x86_64, no-xcode mode. This is the
receipt behind the Ubuntu section of `docs/DISTROS.md`. Raw logs were kept on
the build host at `~/scratch/apple-dev/distro-ubuntu-logs/` (not committed);
the outputs below are quoted from them.

Packages went in by hand per the `apt install` list in `docs/DISTROS.md`
(the apt run itself is not in the kept logs). The swift.org 6.4.0 toolchain
was installed keeping the archive's `usr/` level (`/usr/local/usr/bin` on
PATH), which is the layout `docs/DISTROS.md` prescribes and the logs show in
use: the compiler runs as `/usr/local/usr/bin/swift-frontend`.
